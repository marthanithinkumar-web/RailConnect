# RailConnect

A responsive, mobile-first prototype for exploring illustrative train journey listings.

## Features
- Search and filter by origin, destination, date, and class
- Demo listing cards, illustrative match indicators, and local save functionality
- Create a sample listing stored only in the current browser session/device
- Responsive layout and accessible form labels
- Explicit DEMO / UNVERIFIED labels and railway-rule safety notices

## Safety and scope
This is a frontend prototype, not a live ticket marketplace. It does not verify tickets, availability, user identity, or eligibility; it does not collect PNRs or identity documents, accept payments, or send requests to other users. A reserved ticket may not be transferable. Check current official rules and information through [IRCTC](https://www.irctc.co.in/) before acting. RailConnect is not affiliated with Indian Railways or IRCTC.

## Deploy
The static site is the root `index.html`. It can be hosted on GitHub Pages or any static hosting provider.
